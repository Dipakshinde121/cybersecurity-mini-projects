# Cybersecurity Mini Projects (all in one folder)

| # | Project | Folder | Depends on |
|---|---------|--------|-----------|
| 1 | Build Your Own Cybersecurity Lab | `MP1_Cybersecurity_Lab/` | - |
| 2 | Network Protocol Analysis | `MP2_Network_Protocol_Analysis/` | MP1 lab traffic |
| 3 | AI-Assisted Cybersecurity Threat Model | `MP3_AI_Threat_Model/` | independent |

## Order of work
1. MP1 -> get the lab running, take screenshots as you go
2. MP2 -> capture traffic inside the MP1 lab
3. MP3 -> pure documentation, do it any time

## Rules
- Only scan or attack your OWN lab VMs, on an isolated host-only network.
- Every folder has a `screenshots/` dir. Name files `step-01-what-it-shows.png`.
- Check off the checklists in each README as you go.

## Final submission checklist
- [ ] MP1 report + network diagram + screenshots
- [ ] MP2 report + .pcap files + annotated screenshots
- [ ] MP3 threat model doc + DFD + threat table
- [ ] Your name, roll no., date on each report
